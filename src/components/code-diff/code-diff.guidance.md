# Using CodeDiff well

One file's unified diff, with gutters and annotations anchored to lines.

- Reach for it when the reviewer should judge a concrete change, not read a description of one.
- Show the smallest hunk that carries the decision; a full-file dump asks the reviewer to do your editing.
- Anchor an Annotation to any line whose reason is not obvious from the code itself.
- In a plan, a diff is a proposal: it must match what you intend to write, or the approval is meaningless.
