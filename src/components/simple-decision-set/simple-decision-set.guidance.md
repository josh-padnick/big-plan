# Using SimpleDecisionSet well

**Purpose: collect the small calls that need a word from the reviewer, not a tradeoff card.**

A compact numbered list of quick calls the reviewer can settle in one pass.

- Reach for it near the end of a plan to collect the small open questions that need answers but not tradeoff cards.
- Each decision states its options briefly; if an option needs a paragraph of context, promote the question to a Decision.
- Never mix settled facts into the set; it exists to gather exactly what still needs the reviewer's word.

Choosing between them: `Decision` asks, `ComplexDecision` records, `SimpleDecisionSet` gathers. Decision and ComplexDecision present the same shape - options across, criteria down - on purpose, so a reader who learns one can read the other.
