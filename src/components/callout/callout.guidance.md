# Using Callout well

An accent-bordered panel for the one thing a skimming reviewer must not miss.

- Choose the type by consequence: `note` for context, `tip` for a better path, `warning` for risk, `danger` for harm.
- A callout interrupts reading; use one only when the interruption is the point.
- If a document has more than a few, they stop working; demote ordinary detail back to prose.
