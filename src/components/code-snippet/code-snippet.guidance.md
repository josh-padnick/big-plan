# Using CodeSnippet well

An excerpt of existing code, with optional file identity and file-absolute line numbers.

- Reach for it when the reviewer needs to see current reality: the contract you will preserve or the code you will change.
- Keep the excerpt to the lines that matter and use file-absolute numbering so the reviewer can verify it in place.
- Use CodeDiff for proposed changes; CodeSnippet shows what is, not what will be.
