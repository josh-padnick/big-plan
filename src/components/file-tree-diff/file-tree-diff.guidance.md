# Using FileTreeDiff well

One combined change tree with per-entry added, modified, moved, or deleted status.

- Reach for it when the shape of a change across files is the story: a restructuring, extraction, or migration.
- Every entry the plan creates, moves, or deletes belongs in the tree; an incomplete tree reads as a complete one.
- Pair it with prose for the why; the tree carries the what and where.
