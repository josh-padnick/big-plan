# Fresh-agent wireframe quality proof

The standards now lead with one memorable design test, then move device details and checkable rules beneath it. The product sketches use only public Wireframe guidance and defaults.

## CLEAR is the front door

**Five questions, in order.**

- **C · Clear job.** Does this screen advance one task, with a primary action that names the goal? _Absorbs one-screen-one-job, obvious next action, and goal-matching action._
- **L · Layout follows attention.** Is there one focal point and an effortless reading order? _Absorbs hierarchy, proximity, grouping, scanning, alignment, minimal boxes, contrast, and decoration._
- **E · Explicit change.** Can I see what selection changes, what appears next, and when the mode changes? _Absorbs visible outcomes, progressive disclosure, states, consistency, relationships, and handoff boundaries._
- **A · Audience language.** Would this audience naturally say these concrete words and amounts? _Absorbs tangible language, mental model, emotional goal, and outcome-named actions._
- **R · Real device.** Does it behave like this device while remaining deliberately rough? _Absorbs native shells, aspect ratio, density, affordances, touch size, and fidelity._

The hierarchy is deliberate: **CLEAR** judges the product UI; per-device pass criteria decide native composition; primitives and diagnostics settle facts an agent should not have to remember; **LOOP** is only the render-and-review workflow. **CRAP** remains the separate standard for the plan page around the artboard.

## What the curation removed

**Every previous standard now has one unambiguous home.**

- **Fourteen general principles → CLEAR.** Layout, Explicit change, Audience language, and Real device absorb the review questions.
- **Ten task-flow principles → CLEAR.** They supply Clear job and sharpen the other four questions.
- **STAMP → retired.** Space, Tiers, Align, and Minimal boxes become Layout and contracts; Plain state becomes Explicit change.
- **Per-form-factor principles → pass/reject criteria.** They remain beneath CLEAR for desktop, tablet, and phone.
- **Type, aspect, state, and target rules → mechanics.** Primitives, compile diagnostics, and browser geometry checks own them.
- **LOOP and CRAP → separate jobs.** LOOP proves a render; CRAP structures the plan page around it.
