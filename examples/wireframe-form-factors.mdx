# Harbor across three form factors

Sketch the Harbor support inbox natively for desktop, tablet, and phone.

Each form factor is a parallel prototype of the same product so reviewers compare real device layouts rather than one layout with different captions.

## Desktop web SaaS

Flush shell, narrow nav rail, primary content that dominates secondary rails.
Settings use a Linear-style sub-nav plus one dense field column.
Create is a full page route, not a floating sheet.
