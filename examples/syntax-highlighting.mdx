# Syntax Highlighting Preview

Switch your OS color-scheme preference to compare the light and dark palettes; the export applies it through CSS alone.

## SQL

*A join and aggregate, where keywords, functions, and literals each take their own token color.*

```sql
SELECT users.id, users.email, COUNT(orders.id) AS order_count
FROM users
LEFT JOIN orders ON orders.user_id = users.id
WHERE users.active = true
GROUP BY users.id, users.email
ORDER BY order_count DESC;
```

## TypeScript

*Types, template literals, and a ternary, so the palette is exercised beyond keywords.*

```typescript
type Plan = {
  readonly title: string;
  readonly approved: boolean;
};

export const summarize = (plan: Plan): string =>
  `${plan.title}: ${plan.approved ? "ready" : "needs review"}`;
```

## Bash

*A shebang, a strict-mode line, and a loop with an interpolated variable.*

```bash
#!/usr/bin/env bash
set -euo pipefail

for plan in examples/*.mdx; do
  node bin/big-plan.mjs render "$plan"
done
```

## JSON

*Keys, string values, and an array, which is the smallest useful contrast test.*

```json
{
  "title": "Payments retry architecture",
  "status": "approved",
  "reviewers": ["platform", "payments"]
}
```
