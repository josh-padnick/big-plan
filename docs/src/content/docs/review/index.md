A plan review is one conversation: you read the agent's proposed approach, ask for what you
need, settle the questions it asks, and approve it before any code exists.
Everything in this section happens on your own machine, through `big-plan review`, with no
account and no third-party service.

## How a review runs

1. **Serve the plan.** `big-plan review` takes custody of one plan file and prints the
   address to open and save.
2. **Read and mark it up.** Comment on a slide, a component, or a piece of selected text.
   Ask a plan-wide question in **Chat**.
3. **Settle the questions the plan asks.** Answer its decision cards; the **Inputs** list
   says what is still outstanding.
4. **Read what the agent changed.** Each answered comment carries a change set you walk and
   accept place by place.
5. **Approve.** Approval writes your answers into the plan source, records what you approved,
   and tells the agent to begin.
