Big Plan turns your agent's standard text plan into a rich, interactive HTML document specially designed for human review.

Run it in your favorite agent harness as a skill like this:

  </TabItem>
  <TabItem label="Codex">

  </TabItem>
</Tabs>

## Philosophy

Three beliefs drive every design decision.

**Plans are for human review.**
The one reader who matters is the human who has to agree to the plan, so everything is judged by one test: does it help a person read, question, and decide?

**Components make review first-class.**
A code change wants a diff, a schema wants a table, a risk wants to stand out.
Typed components render each kind of information the way humans consume it, instead of flattening everything into prose.

**Plans are local and private.**
Plans carry sensitive context, so the whole loop stays on your disk: no account, no server, no external requests.

## How it works

1. Your agent writes its plan to a markdown file.
2. You run `npx big-plan render plan.md`.
3. You open the rendered document and review it.
4. If you want changes, tell the agent; it revises the file, and you render again.

Big Plan works with any agent that can write a file: Claude Code, Codex, Cursor, or your own.
