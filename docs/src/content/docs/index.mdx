Your agent writes the plan. Big Plan renders it as a document built for review, on your machine,
with no account and no third-party service.

## Set it up with one prompt

Paste this into your coding agent:

```text
Set up Big Plan for me: read https://bigplan.dev/setup.md and follow it.
```

<InstallPrompt prompt="Set up Big Plan for me: read https://bigplan.dev/setup.md and follow it." />

It needs Node.js 22 or newer, and it installs nothing globally. The linked
[setup guide](/setup.md) stays current as Big Plan changes, so the prompt never does.

Prefer to do it yourself? `npx -y big-plan@latest guidance` prints the plan-writing principles
and unlocks the rest of the workflow for that directory.

## What a plan is made of

A plan is Markdown plus a closed set of components, so every plan renders into the same
document shape. The agent spends its effort on the decisions rather than the presentation.
