:::caution[Pre-alpha]
Big Plan is under active development.
The static markdown viewer works today; the rest of the review experience is still being built.
:::

Big Plan turns your agent's markdown plan into a document built for review, so you reach real agreement before the agent acts.
One command, one self-contained HTML file, everything on your machine:

```sh
npx big-plan render plan.md
```
