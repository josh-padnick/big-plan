<Part title="Context" />

## Status quo

- Prose CSS selected semantic tags under `article`.
- Registered component chrome used some of the same tags.
- Decision rows inherited a 728 px reading measure and a list-item margin.
- DataTable Truncate mode forced equal columns.
- The FlowDiagram Fit state used a green accent.
- Plain code figures had no Copy control.
- The legacy copy fallback reported success when the browser returned `false`.

## Success looks like

- Only authored Markdown gets prose-flow styles.
- All 18 registered components control their own chrome.
- Authored prose inside a component keeps its reading styles.
- Fit uses a clear neutral gray in both themes.
- Wrap and Truncate use the same content-proportional widths until content is too wide.
- Copy uses only the code text and reports a true failure.
- The schema figure defines each repeated presentation class once.

## Prose has an explicit boundary

The renderer marks Markdown-origin HAST with `data-authored-prose`.
It adds the marker before the React component delivery edge.
Prose CSS now requires this marker.
Component chrome does not get the marker.

## Fit has a neutral state

The pressed Fit control now uses the `edge` background, the `edge-strong` border, and the `ink` label.
The state is gray in light and dark themes.
It does not use the accent color.

Use the Fit control in the diagram above.
Check that the pressed state is clear and neutral.
The group, separators, target size, and control order do not change.

## Truncate keeps proportional widths

Truncate now keeps automatic table layout.
It applies an 18 rem limit only to a cell that is too wide.
It does not make every column equal.

| Mode | Figure width | Column widths | Evidence cell |
| --- | ---: | --- | --- |
| Wrap | 585.0625 px | 147.234375 / 90.6875 / 136.1875 / 208.953125 px | client 209 px / scroll 209 px |
| Truncate | 585.0625 px | 147.234375 / 90.6875 / 136.1875 / 208.953125 px | client 209 px / scroll 209 px |
| Truncate with long content | 664.109375 px | 147.234375 / 90.6875 / 136.1875 / 288 px | client 288 px / scroll 882 px |

The old Truncate figure was 786.8125 px.
It used four 196.203125 px columns.
It clipped the 209 px Evidence content in a 196 px cell.

## Copy uses exact text and correct feedback

Plain code figures now show Copy above Maximize.
Both controls have a 24 by 24 px target.
Copy reads only the direct `pre > code` text.
It removes only the structural final newline.
It does not copy a title or control label.

Use Copy on this example:

```http
POST /api/plans/demo/review-events HTTP/1.1
Content-Type: application/json

{"kind":"comment","body":"Keep this exact text."}
```

The label changes to `Copied code` after success.
If the Clipboard API is not available, the viewer uses `execCommand`.
If `execCommand` returns `false`, the label changes to `Copy failed`.
The viewer always removes its temporary text field.

## Schema styles have local owners

`SchemaCode` owns code styles and its complete neutral or muted variant.
`SchemaCell` owns each cell role.
`MutedText` owns repeated secondary-text shapes in the layout and header files.
`SectionLabel` and complete static lookups own the remaining layout variants.

Each Tailwind candidate is a complete source string.
The implementation does not build class names at run time.
The extraction changes no rendered pixels.

## Try the changes

Run these commands from the repository root:

```sh
bun run build
node bin/big-plan.mjs guidance
node bin/big-plan.mjs validate .big-plan/gallery-rendering-fixes-review.mdx
node bin/big-plan.mjs render .big-plan/gallery-rendering-fixes-review.mdx .big-plan/gallery-rendering-fixes-review.html
node bin/big-plan.mjs render examples/all-components.mdx .big-plan/all-components-pr64.html
python3 -m http.server 8000 --directory .big-plan
```

Open `http://localhost:8000/gallery-rendering-fixes-review.html`.
Open `http://localhost:8000/all-components-pr64.html` for the complete gallery.

Run the focused fallback test:

```sh
bunx playwright test test/component-interactions.spec.ts --grep "failed legacy copy"
```

Run the exact replay gate:

```sh
bun run verify:style-history -- --base fm/bp-tailwind-a-fb --artifacts test-results/style-history/review-followups
```

## Review checklist

- Check Decision, QuickDecision, and DecisionAnalysis at the full component width.
- Check that Decision rows have no prose list margin below them.
- Check that authored Markdown still has the normal reading measure.
- Toggle the theme and press Fit. Check for a clear neutral state.
- Select Wrap and Truncate in the Rollout gates table. Check that the columns keep the same proportions.
- Copy the HTTP example. Check that the result starts with `POST` and ends with `}`.
- Run the fallback test. Check that a false result shows `Copy failed`.
- Check the schema figure in both themes. Confirm that the extraction changes no pixels.
