# Three ways to ask one question

Same decision, same words, three shapes - judged only by how little the reader must hold to answer.

<QuickSummary>

<Why>

- A decision the reader has to decode is a decision they postpone.

</Why>

<What>

- One question rendered three ways, so the cheapest to read can win on evidence.

</What>

<How>

- Cut what each shape asks the reader to process, then count it.

</How>

</QuickSummary>

## What you are comparing

_Read each one cold and notice how much work it takes to answer._

Every shape below renders the same decision with the same words.
Only the arrangement differs, so any difference in effort is the arrangement's doing.

Three reductions apply to all of them, because they were weight rather than information:

- A verdict is one signal, the word. The glyph and the hue said the same thing twice more.
- A criterion every option scores identically never renders, because it cannot inform a choice.
- The rationale no longer restates the criteria the reader just read.

## The component model

_Three instances of one component, not three components._

Variations A, B, and C each exercise the built-in `Decision` component through its `layout` attribute:

- A is `<Decision layout="rows">`.
- B is `<Decision layout="matrix">`.
- C is `<Decision layout="brief">`.

They are not `SmallDecision`, `ComplexDecision`, or separate component types.

The already-approved component boundary remains: `Decision` asks the reviewer a question and ends in a confirmed answer; `ComplexDecision` records a weighted analysis for the reviewer to audit. They stay two components because they own different jobs.

Their matrix-shaped presentations share the internal `ComparisonMatrix` primitive so the two components do not drift into different visual dialects. In this document, B uses that primitive directly and C uses it inside the on-demand comparison; A is the row presentation of `Decision`.

## How to choose

_Pick the cheapest shape that still supports a real choice._

1. Every shape renders the same decision, so any difference in effort belongs to the shape.
2. A verdict reaches the reader as one signal, never as a word and a glyph and a hue saying the same thing.
3. A criterion that every option scores the same never renders.
4. Choosing an option never moves anything else on the page.
5. Every shape can be answered with the keyboard alone and read with scripts disabled.
