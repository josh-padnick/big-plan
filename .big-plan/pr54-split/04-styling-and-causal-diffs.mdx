## The contract pass

**Style ownership.** A repository check enforces utility-first styling, explicit CSS escape-hatch rationale, layer rules, and complete static Tailwind candidates.

**Visual evidence.** Style-history configuration and replay coverage protect anchored comments, lifecycle cards, toolbars, motion, branding, and responsive states across the migration.

**Capture bridge.** The style-history harness now promotes a draft through a valid server bootstrap before reloading. That makes the configured expanded-thread capture exercise the same ownership boundary as production: sent comments come from server state, not browser-local recovery state.

The same bridge removes a real raster flake without weakening the zero-pixel contract. Repeated hosted runs had alternated between two hashes that differed at only eight one-channel pixels on two rounded-card corners. Geometry, text, fonts, and motion were identical; the remaining source was Skia selecting CPU-specific antialias paths. Captures now disable Skia runtime CPU optimizations, pin sRGB and device scale, disable animations and transitions, and write only after two consecutive settled frames are byte-identical.

**Stable history.** A capture-config addition applies to its own before/after pair, but cannot retroactively reinterpret an earlier approved manifest. The verifier uses the child commit's declared config for each pair while executing it with the current deterministic harness.

**Atomic browser evidence.** A separate test bridge keeps the toolbar control's focus and geometry observation in one successful poll. The review runtime can replace that toolbar node while focus state settles, so resolving a live locator again afterward was nondeterministic.

**Causal revisions.** Request claims become immutable, response resolution belongs to the exchange, and one claimed source revision advances per agent turn.

**Diff correctness.** Removal anchors stay within their section, inexact mappings remain historical, and unchanged structural moves disappear from the change tour.

## Review boundaries

- This slice owns the Tailwind conversion and its visual-contract tooling.
- It owns one clearly labeled capture-harness bridge. PR 54's source tree declared the expanded-thread light/dark captures but could not produce them because its harness promoted the draft only in browser-local state; the production runtime correctly accepts sent comments only from server bootstrap state.
- That bridge also fixes the pre-existing exact-pixel flake at its source. It preserves the zero-pixel rule: no blanket threshold, per-channel tolerance, or ignored region is introduced.
- The same bridge scopes replay config by commit, so adding later capture keys cannot change earlier approved evidence.
- A separate one-file Playwright bridge fixes the live-locator replacement race instead of retrying around it.
- It includes rounds twenty-one through twenty-three because their replay and causality fixes close the migration's review contract.
- It does not add atomic persistence, interrupted-write recovery, stale-tab merging, or post-rebase identity repair.
- Component-owned typed revision lenses are isolated in the final slice.

## Acceptance criteria

**Build and visual evidence.**

- `bun run build`, `bun run lint`, `bun run test`, and `bun run test:e2e` pass on this branch.
- Styling-contract and style-history checks accept every styling commit in the slice.
- The final capture harness produces all 34 configured captures, including `components__expanded-thread-reply__desktop__light.png` and `components__expanded-thread-reply__desktop__dark.png`.
- Identical capture matrices produce identical PNG bytes across repeated local and hosted runs.
- A regression test proves that a later capture-key addition cannot reinterpret an earlier approved manifest.
- Visual-empty commits remain pixel-identical; this slice's intentional Tailwind delta carries exact approved evidence for 28 captures and 1,035,563 changed pixels.
- The live-toolbar focus journey obtains focus and its non-null geometry from the same successful poll iteration.

**Revision truth.**

- One agent turn owns exactly one immutable claim and causal revision.
- Diff anchors, historical mappings, and structural-move suppression match the source revisions.
