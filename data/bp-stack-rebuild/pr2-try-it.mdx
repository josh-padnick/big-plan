# Review an agent-authored revision

Use the same thin thread kernel while a real coding-agent session rewrites this
plan and reports only outcomes Big Plan can verify.

## Inspect revision truth

The API writes a job and returns immediately. A worker leases the oldest ready
job, applies exponential backoff, and records the terminal outcome.

After the coding agent responds, choose **What changed** before reloading. Then
reload the revised plan. If the original sentence disappeared, its thread must
say that the recorded target is unavailable instead of guessing a nearby
replacement.

<CodeSnippet file="src/retry/next-delay.ts" startLine="1" showLineNumbers>

```ts
export const nextDelay = (attempt: number): number =>
  Math.min(30_000, 500 * 2 ** attempt);
```

## Ready when revision truth is visible

- A sent note stays **With agent** until a validated response exists.
- A changed outcome names a block present in the computed revision diff.
- The basic diff distinguishes added, removed, and rewritten authored blocks.
- Exact structural paths re-anchor; missing paths remain visibly orphaned.
